# Kapital Kitchen — Website

Official-style 3-page website for **Kapital Kitchen** (Steak House, Coffee & Resto), Town Hall Road, Rahim Yar Khan.

## Pages
- `index.html` — Home: hero, why Kapital Kitchen, customer favourites with prices, visit info
- `menu.html` — Full menu with prices + the original menu cards
- `contact.html` — Contact details, hours, map, and a message form that opens WhatsApp
- `style.css` — Shared stylesheet (brand colours taken from the restaurant's own logo: orange #E98400 + black)

## Menu source
Menu items and prices are from the restaurant's own "Updated Menu — June 2026" post on its Facebook page (facebook.com/kapitalkitchenryk), retrieved 26 Oct 2026. All prices are in PKR and subject to a 10% service charge, as printed on the menu cards. Menu card images are embedded in `menu.html` so the site works without extra image files.
